## 🛠️ 技术栈

- **前端核心**：React 18 / 19 + Vite
- **UI 风格**：Cosmic Glassmorphism + Sacred Geometry (深空毛玻璃拟态与神圣几何)
- **样式与排版**：Tailwind CSS + Google Fonts (Cinzel / Outfit) + Lucide Icons
- **声景引擎**：Web Audio API 纯代码合成器 (432Hz 宇宙白噪音、水晶钵共振、翻牌音效)
- **图形与导出**：HTML5 Canvas + SVG Astrolabe + html2canvas + canvas-confetti
- **云端服务**：Firebase 11 (Authentication + Cloud Firestore + Hosting)
